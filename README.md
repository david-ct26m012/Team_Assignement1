# CONFZone – FrontendNow Begleit-App

Eine moderne Vue 3 + TypeScript Anwendung für die **FrontendNow** Konferenz. Dieses Repository enthält das vollständige Projekt-Grundgerüst (Task E) als Basis für die weiteren Entwicklungsschritte.

---

## 🚀 Schnellstart

Folge diesen Befehlen, um das Projekt lokal auszuführen:

### 1. Abhängigkeiten installieren
```sh
npm install
```

### 2. Entwicklungs-Server starten
```sh
npm run dev
```

Nach dem Start ist die Anwendung unter http://localhost:5173 im Browser erreichbar.
